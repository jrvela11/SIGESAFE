# SIGESAFE

⚙️ Tecnologías del Proyecto
🧩 Arquitectura General

El proyecto utiliza una arquitectura desacoplada (frontend + backend), donde cada parte funciona de manera independiente y se comunica a través de una API REST.

🔹 Frontend

El frontend está desarrollado con las siguientes tecnologías:

React JS: Librería principal para la construcción de interfaces de usuario dinámicas.
JavaScript (ES6+): Lenguaje base para la lógica del cliente.
Vite (o Create React App): Herramienta para la configuración y ejecución del proyecto.
Fetch API: Método nativo de JavaScript para realizar peticiones HTTP al backend.
React Router: Manejo de rutas y navegación dentro de la aplicación.
HTML5 + CSS3: Estructura y estilos de la interfaz.
🔹 Backend

El backend está desarrollado como una API REST utilizando:

Laravel: Framework PHP para la lógica del servidor.
PHP 8+: Lenguaje principal del backend.
MySQL: Sistema de gestión de base de datos relacional.
Laravel Eloquent ORM: Manejo de base de datos mediante modelos.
🔗 Comunicación
API REST: Permite la comunicación entre frontend y backend.
HTTP/HTTPS: Protocolo utilizado para el intercambio de datos.
JSON: Formato estándar para enviar y recibir información.
Fetch API: Utilizada en el frontend para consumir los endpoints del backend.
🛠️ Herramientas de Desarrollo
Git: Control de versiones.
GitHub: Repositorio remoto y colaboración en equipo.
Postman: Pruebas de endpoints de la API.
Node.js y npm: Gestión de paquetes para el frontend.
Composer: Gestión de dependencias en Laravel.
